# 3D Interaktiv Ta'lim — MVP 0.1

Bu loyiha oddiy HTML fayl emas, kengaytiriladigan Next.js + TypeScript ilovasi uchun boshlang‘ich kod bazasi.

## Ishga tushirish
1. Node.js 20 yoki undan yangisini o‘rnating.
2. Terminalda loyiha papkasiga kiring.
3. `npm install`
4. `npm run dev`
5. Brauzerda `http://localhost:3000` ni oching.

## Hozirgi MVP
- O‘quvchi bosh sahifasi va fan xaritasi.
- 1-sinf matematika uchun birinchi mavzu kartasi.
- Mavzu sahifasi: maqsad, kuzatish, shakl/rang/o‘lcham mashqi.
- To‘g‘ri javob uchun yulduz va progress.
- Natija brauzerning localStorage xotirasida saqlanadi.

## Keyingi texnik bosqich
- Three.js / React Three Fiber bilan haqiqiy 3D laboratoriya.

- O‘qituvchi va ota-ona kabinetlari.
